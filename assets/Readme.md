## Políticas del Repositorio
1. [cite_start]**Rama Principal:** `main`[cite: 104]. [cite_start]Ningún integrante puede realizar cambios directamente sobre esta rama[cite: 103].
2. [cite_start]**Rama de Integración:** `develop`[cite: 124].
3. [cite_start]Todo cambio debe originarse desde una rama `feature`[cite: 106].
4. [cite_start]Todo cambio debe integrarse mediante Pull Request[cite: 108]. [cite_start]El Pull Request debe incluir: título descriptivo, descripción de cambios y evidencia de pruebas realizadas[cite: 110, 111, 112, 113].
