# TaskManager

## Descripción
Aplicación web para la empresa SoftDev Solutions. Su objetivo principal es administrar tareas y actividades de un equipo de trabajo

## Tecnologías Utilizadas
* HTML5
* CSS3
* JavaScript

## Equipo de Desarrollo y Roles

| :--- | :--- | :--- | :--- |
| **Administrador** | Ricardo | Gestiona ramas y aprobaciones  / Módulo de registro | Total (Lectura, Escritura, Merge a Main) |
| **Desarrollador 1** | Oswaldo | Módulo de login | Lectura y Escritura (Ramas Feature) |
| **Desarrollador 2** | Alan | Módulo de la página principal | Lectura y Escritura (Ramas Feature) |

*Nota: La documentación es responsabilidad compartida de todo el equipo.*

## Políticas del Repositorio
1. **Rama Principal:** `main`. Ningún integrante puede realizar cambios directamente sobre esta rama.
2. **Rama de Integración:** `develop`.
3. Todo cambio debe originarse desde una rama `feature`.
4. Todo cambio debe integrarse mediante Pull Request. El Pull Request debe incluir: título descriptivo, descripción de cambios y evidencia de pruebas realizadas.
